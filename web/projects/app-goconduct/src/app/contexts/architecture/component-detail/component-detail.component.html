Ca · afferent coupling
How many components import this one. High means a change here reaches many.
Ce · efferent coupling
How many components this one imports. High means it changes when any of them does.
I · instability
Ce ÷ (Ca + Ce). Zero means stable: hard to change because many depend on it. One means unstable: nothing depends on it, so it can change at any time.
A · abstractness
Interfaces ÷ all types. A stable component should be abstract, so others extend it instead of changing it.
D · distance
|A + I − 1|. How far the component is from the balance line. Zero is on the line. One is in a corner: stable and concrete, or abstract and unused.
